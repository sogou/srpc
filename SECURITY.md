# Security Policy

## Supported Versions

Only the latest release receives security fixes. Fixes are not backported
to older versions. Please check that the issue still reproduces on the
latest release before reporting.

| Version        | Supported |
| -------------- | --------- |
| latest release | Yes       |
| older releases | No        |

## Reporting a Vulnerability

Please do not report security issues through public issues, pull requests or
discussions.

Email holmesyxli@tencent.com instead.

Please include:

- the affected version or commit
- the protocol or component involved (for example BRPC, TRPC, HTTP)
- steps or a small program to reproduce the issue
- the impact as you understand it

We aim to acknowledge your report within 7 days, and we will keep you
informed while we work on a fix. Once a fixed release is available, we will publish a GitHub
security advisory, request a CVE where appropriate, and credit you unless you
prefer otherwise.
